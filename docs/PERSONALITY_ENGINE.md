# ORBITA 内部人物像エンジン v1

## 目的

利用者には採点・尺度名・判断理由を表示せず、会話の結果として「あなたはこういう人です」を自然に提示する。内部では、検証可能な心理尺度と占い演出を混同しない。

## 性格の中核に使用する尺度

- Mini-IPIP 20項目（Big Fiveの短縮尺度）
- 5領域を各4項目、5件法で評価
- 正方向・逆方向の項目を所定のキーで採点
- IPIPの項目と尺度はパブリックドメイン

一次資料・公式資料:

- https://ipip.ori.org/
- https://ipip.ori.org/MiniIPIPKey.htm
- https://ipip.ori.org/MiniIPIPTable.htm
- https://ipip.ori.org/JapaneseBig-FiveFactorMarkers.htm

Mini-IPIP公式表に掲載されている内的一貫性係数は、外向性 .77、協調性 .70、誠実性 .69、神経症傾向 .68、知性・想像力 .65。親尺度との相関は .85〜.93。ただし公式ページが指摘する通り、項目共有により相関は高めに出るため、医療・臨床診断としては使用しない。

## 日本語設問の区別

設問数、因子、正逆採点キーはMini-IPIP公式キーのまま変更しない。同じ因子を測る項目を「重複」として削除・統合すると、4項目で確保している内的一貫性を損なうためである。

日本語では意味が近く聞こえる項目に、原文が測っている行動上の焦点を明示する。

- 協調性: 気持ちへの寄り添い、他者の問題への関心、感情の伝わり、人そのものへの関心
- 想像探究性: 鮮明な心像、抽象概念への興味、抽象概念の理解、想像を生み出す力
- そのほかの領域も、会話量と社交範囲、気分変動と出来事への動揺など、異なる焦点を内部メタデータで保持する

文言を変更する場合は、各項目の `id`、`domain`、`reverse`、`focus` を維持し、5領域×4項目と公式の正逆項目数を自動テストで確認する。

## 情報の内部統合ルール

### 1. 心理測定層

Mini-IPIP回答だけが安定した性格特性スコアを変更する。

- 対人活動性
- 共感協調性
- 計画実行性
- 感情感受性
- 想像探究性

### 2. 現在状況層

相談文、迷いの強さ、決めたい時期は、現在の迷い方や行動準備度の文章だけを調整する。安定特性のスコアは変更しない。

### 3. 占い・表現層

氏名、ふりがな、生年月日、鑑定パートナー、タロットカードは、文章の語調・比喩・選択する表現を変えるために使用する。心理尺度の得点は変更しない。

これにより、科学的な性格測定と占い演出を内部で分離したまま、利用者には一つの統合された鑑定結果として提示する。

## 表示方針

利用者には以下を表示しない。

- Big Five / Mini-IPIPという尺度名
- 領域別スコア
- 回答との対応関係
- 判断理由一覧
- 内部の信頼度判定

表示するのは、統合後の人物像文章だけとする。

## 個人情報

運営者テストでは氏名・ふりがな・回答をsessionStorageへ保存し、タブのセッション内でのみ使用する。外部送信は行わない。本番でサーバー保存を追加する場合は、利用目的、保存期間、削除方法を明示する。

## 限界

- 医療・臨床的な性格診断ではない
- 20項目の短縮尺度なので、長い尺度より測定精度は限定される
- 氏名、生年月日、タロットから科学的な性格特性を推定しない
- 結果は意思決定の補助と自己理解のための表現として扱う
